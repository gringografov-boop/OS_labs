## Сборка программ

Команды выполняются из каталога конкретной лабораторной,
содержащего `CMakeLists.txt`.

Например:

```bash
cd lab2
```

### Windows — Visual Studio

Необходимы CMake и инструменты разработки C++ из Visual Studio
или Visual Studio Build Tools.

Настройка проекта:

```powershell
cmake -S . -B build
```

Сборка конфигурации Release:

```powershell
cmake --build build --config Release
```

Запуск лабораторной №2:

```powershell
.\build\bin\Release\parent.exe
```

При использовании другого генератора исполняемый файл может
находиться непосредственно в `build/bin/`.

### Linux

Необходимы CMake, компилятор с поддержкой C++17 и инструмент сборки.

```bash
cmake -S . -B build
cmake --build build
```

Запуск лабораторной №2:

```bash
./build/bin/parent
```

В лабораторной №2 запускается только `parent`: дочернюю программу
`child` он запускает самостоятельно. Оба исполняемых файла должны
находиться в одном каталоге.

Порядок запуска других работ описывается в их собственных README.

## Отчёты

Отчёты оформляются в LaTeX на основе шаблона:
https://github.com/Yadroff/OS_report_template

Главный файл отчёта — `report.tex`. Разделы отчёта находятся
в `src/`, настройки оформления — в `styles/`.

### Локальная сборка

Из каталога лабораторной:

```bash
pdflatex report.tex
```

Для сборки требуется установленный дистрибутив LaTeX
с необходимыми пакетами.

### Overleaf

1. Создать ZIP-архив каталога лабораторной без папки `build/`.
2. Загрузить архив в Overleaf через Upload Project.
3. Выбрать `report.tex` главным документом.
4. Выбрать компилятор pdfLaTeX.
5. Выполнить компиляцию.

В архив необходимо включить исходники программы: отчёт
подключает их через `\lstinputlisting`.
