\section{Условие}
{\bfseries Цель работы:} приобрести практические навыки управления процессами и организации межпроцессного обмена данными посредством каналов.

{\bfseries Задание:} реализовать отдельные родительскую и дочернюю программы для Linux и Windows. Родитель должен создать дочерний процесс и организовать обмен данными через два канала. Ошибки системных вызовов должны обрабатываться.

{\bfseries Вариант:} 5.

Родительский процесс первой строкой получает имя файла, а затем принимает по одному целому числу. Числа передаются дочернему процессу через первый канал. Дочерний процесс проверяет число на простоту. Составные числа записываются в файл. При получении отрицательного или простого числа дочерний процесс отправляет родителю сообщение через второй канал, после чего оба процесса завершаются.
