# Проверка поставки

Проверено в Linux-песочнице 28 октября 2026 года. Результаты ниже относятся к этому архиву, а не к непроверенному коду из предыдущих сообщений.

| Проверка | Фактический результат |
|---|---|
| Общая сборка Linux, Debug, `-Werror` | Успешно |
| 23 интеграционных теста Linux Debug | Все пройдены |
| Самостоятельная сборка `cmake -S lab2`, Release | Успешно |
| 23 интеграционных теста Linux Release | Все пройдены |
| Linux Debug с UndefinedBehaviorSanitizer, `-fno-sanitize-recover=all` | Сборка и все 23 теста успешны |
| Windows Release, MinGW x86_64, `-Werror` | `parent.exe` и `child.exe` успешно скомпилированы и слинкованы |
| Трассировка Linux `strace -f` | Проверены запуск ребёнка, `dup2`, pipe и ожидание `wait4` |
| Интеграция в скачанную структуру преподавателя | Установщик, сборка и все 23 теста успешны |
| Повторный запуск установщика | Резервные копии созданы; CMake-блок не дублируется |
| Интеграция с существующим корневым CMake | Исходное содержимое сохранено, сборка успешна |
| Отдельная проверка аварийного выхода ребёнка после готовности | Родитель вернул ошибку без зависания и завершения по SIGPIPE |

На настоящей Windows и в MSVC программа в этой среде не запускалась. Проверка MinGW подтверждает компиляцию Windows-ветки, но не гарантирует отсутствие особенностей среды исполнения Windows. Тесты подготовлены и для Windows, чтобы их можно было повторить после локальной сборки.

## Покрытие

- Составные числа записываются, первое простое останавливает обработку.
- Отрицательное значение, `2`, `INT_MAX`, `INT_MIN`.
- `0` и `1` пропускаются.
- EOF сразу после имени файла и после числа без последнего перевода строки.
- Текст, пустая строка, несколько чисел, переполнение int.
- Пробелы, знак `+`, Windows-переводы строк.
- Строка 200 000 символов: не зависает на ограниченном буфере pipe.
- Последовательность 300 составных чисел.
- Имя выходного файла с пробелами и Unicode.
- Путь к исполняемым файлам с пробелами.
- Ошибка открытия выходного файла, отсутствие ребёнка, ошибка `exec`.
- Неправильное число аргументов ребёнка.

Исходные тестовые входы искусственные по определению: это тестовые случаи, не результаты измерений и не данные эксперимента по производительности.
